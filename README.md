# Job Search Kit

Фреймворк поиска работы для Claude Code. Агент ищет вакансии, отсеивает лишнее, собирает CV и
письмо под каждую роль, заполняет форму отклика и ведёт трекер. Ты отвечаешь на вопросы и
подтверждаешь отправку.

Сделан для продуктовых ролей, но всё личное и все фильтры — в одном профиле: под аналитика,
дизайнера или маркетолога меняется профиль, а не код.

## Как это работает

```
 /onboard ──► /cv-interview ──► /positioning          один раз, ~1–2 часа разговора
    │              │                 │
    ▼              ▼                 ▼
 me/profile    me/experience-    me/positioning       личное, только на твоём компьютере
 me/answers      bank, cv/         + варианты CV

 /jobs-run  (каждый заход, 10 подач по умолчанию)
   поиск ──► дубль? ──► гейты ──► оценка ──► CV + письмо ──► форма ──► [ты: «отправляй»] ──► трекер
   scan.py   tracker    JD, гео,   балл с     render_cv.py     Chrome                    data/tracker.csv
                        вилка      доказат.   text_audit.py
```

## Что нужно

1. **Claude Code** — приложение Claude (вкладка Code) или CLI `claude`. Нужна подписка Claude
   Pro/Max или API-ключ.
2. **Python 3.10+** — на Mac проверить: `python3 --version`. Нет — `brew install python`
   или python.org.
3. **Chrome + расширение Claude** (Claude in Chrome) — чтобы агент сам заполнял формы. Без него
   работает всё, кроме форм: поиск, CV, письма, трекер.
4. Желательно: **LibreOffice** для PDF (`brew install --cask libreoffice`) и **отдельный email**
   под поиск работы.

Ключи API не нужны: поиск идёт по открытым источникам, оценку и тексты делает сам Claude.

## Старт за 3 шага

1. Скопируй папку `job-search-kit` куда удобно (например, в `~/job-search`).
2. Открой её в Claude Code: в приложении — «Open folder», в терминале — `cd ~/job-search && claude`.
3. Напиши `/onboard` (или просто «привет, начнём»). Агент поставит зависимости, попросит резюме
   и проведёт по вопросам.

Дальше — `/cv-interview`, `/positioning`, и можно искать: `/find` или `/jobs-run`.

## Команды

| Команда | Что делает |
|---|---|
| `/onboard` | знакомство: импорт резюме, контакты, цели, гео, деньги, настройки |
| `/cv-interview` | разбор опыта: вопросы по каждому месту работы, цифры, истории для интервью |
| `/positioning` | 2–4 трека позиционирования с тайтлами, саммари и вариантами CV |
| `/find` | свежий поиск, отсев, оценка — очередь в трекер, без подачи |
| `/apply <ссылка>` | одна вакансия: CV и письмо под неё, форма до кнопки «отправить» |
| `/jobs-run [N]` | полный заход: поиск → отбор → N подач пачкой → отчёт |
| `/cv [трек/вакансия]` | собрать CV: базовое, под трек или под вакансию |
| `/status [новости]` | воронка, кто ответил, что пора сделать, обновить статусы |
| `/interview-prep <компания>` | подготовка к интервью и мок-интервью |

Можно и без команд, обычными словами: «найди 5 вакансий growth PM в Европе», «перепиши саммари
короче», «из Acme пришёл отказ».

## Где что лежит

```
CLAUDE.md          правила агента (границы, отбор, тексты, формы)
GLOSSARY.md        слова фреймворка
playbooks/         как делать каждый шаг: онбординг, вопросы по CV, позиционирование,
                   оценка, CV, письмо, формы, источники, контакты, интервью, хранение данных
.claude/commands/  команды (промпты) — можно править под себя
scripts/           tracker.py · scan.py · render_cv.py · text_audit.py · form_check.js · doctor.py
config/            ats_orgs.txt — борды компаний для поиска (стартовый список, веди под себя)
templates/         пустые формы личных файлов
me/   (создаётся)  ЛИЧНОЕ: профиль, факты о себе, позиционирование, ответы анкет, данные CV
data/ (создаётся)  трекер, папка на каждый отклик, журнал поиска
```

## Безопасность и приватность

- `me/` и `data/` закрыты `.gitignore` и никуда не отправляются, кроме формы, которую ты одобрил.
- Агент **не** вводит пароли и карты, не проходит капчу, не создаёт аккаунты, не принимает офферы.
- Кто жмёт «Отправить» — настраиваешь в `me/profile.yaml` → `autonomy.submit_mode`. По умолчанию — ты.
- Сообщения рекрутёрам — черновики; отправляешь ты (или агент по прямой просьбе, если включено).
- Агент не выдумывает опыт: цифры в CV и письмах — только из `me/experience-bank.md`,
  `scripts/text_audit.py` это проверяет.

## Обновить фреймворк

Новую версию папки кладёшь поверх старой, **кроме `me/` и `data/`** — там твои данные. Свои правки
команд и плейбуков лучше держать в git (личное он не видит).

## Если что-то не работает

- `python3 scripts/doctor.py --test` — покажет, чего не хватает.
- Поиск даёт мало — `playbooks/job-sources.md` §5.
- Форма не заполняется — `playbooks/forms.md` (ловушки каждого движка).
