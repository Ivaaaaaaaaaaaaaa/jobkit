# jobkit — поиск работы с Claude Code

Плагин для Claude Code. Агент берёт твоё резюме и LinkedIn, настраивает поиск под твою роль и гео,
каждый день находит свежие вакансии на сайтах компаний, собирает CV и письмо под каждую, заполняет
форму отклика до кнопки «Отправить» и ведёт трекер. Ты отвечаешь на вопросы и подтверждаешь отправку.

## Что нужно

- **Claude Code** — приложение Claude (вкладка Code) или CLI `claude`; подписка Pro/Max.
- **Python 3.9+** — на Mac уже есть (`python3 --version`; если Mac попросит поставить инструменты
  разработчика — согласись). Нет совсем — `brew install python`.
- **Chrome + расширение Claude** — чтобы агент сам заполнял формы. Без него работает всё остальное.
- Необязательно: LibreOffice для PDF (`brew install --cask libreoffice`), отдельный email под поиск.

Библиотеки ставить руками не нужно: установщик сам создаёт окружение `~/.jobkit/venv`.

## Установка — 3 шага

1. Создай папку под поиск и открой её в Claude Code (например, `~/job-search`).
2. Поставь плагин:
   ```
   /plugin marketplace add Ivaaaaaaaaaaaaaa/jobkit
   /plugin install jobkit@jobkit
   ```
   (Из архива: `/plugin marketplace add ~/Downloads/jobkit`.)
3. Напиши `/jobkit:setup` и пришли резюме.

Как всё устроено и что делать каждый день — [GUIDE.md](GUIDE.md).

## Как выглядит онбординг (`/jobkit:setup`, ~30–60 минут)

```
0 Как это  схема работы, что агент делает сам и чего не делает никогда
1 Машина     проверка Python, окружение и библиотеки, LibreOffice, папки me/ и data/, разрешения
2 Браузер    проверка расширения Claude in Chrome (если нет — короткая инструкция)
3 Импорт     резюме (PDF/DOCX) + LinkedIn (Профиль → Ещё → Сохранить в PDF) → факты и CV-данные
4 Профиль    роли и уровень · гео, право работы, переезд · деньги · контакты · кто жмёт «Отправить»
5 Борды      300 компаний проверяются под твою роль и гео → свой список (~1 минута)
6 Первый     поиск: топ свежих вакансий прямо сейчас
```
Можно прервать и продолжить: агент продолжает с места остановки. Дальше по желанию:
`/jobkit:cv-interview` (разбор опыта — CV станет сильнее) и `/jobkit:positioning` (2–4 варианта
позиционирования и CV под каждый).

## Команды

| Команда | Что делает |
|---|---|
| `/jobkit:setup` | установка и онбординг |
| `/jobkit:cv-interview` | разбор опыта: цифры, истории для интервью, варианты CV |
| `/jobkit:positioning` | треки позиционирования с тайтлами и саммари |
| `/jobkit:find` | свежий поиск и отбор — очередь в трекер |
| `/jobkit:apply <ссылка>` | одна вакансия: CV, письмо, форма до кнопки |
| `/jobkit:jobs-run [N]` | полный заход: поиск → N подач → отчёт |
| `/jobkit:cv` | собрать CV: базовое, под трек, под вакансию |
| `/jobkit:pipeline` | воронка, кто ответил, что пора сделать |
| `/jobkit:interview-prep <компания>` | подготовка и мок-интервью |
| `/jobkit:debrief <компания>` | разбор звонка: оценка, ошибки со счётом, ответы лучше, письмо после |
| `/jobkit:stats` | метрики: что работает, где воронка течёт |
| `/jobkit:support` | сообщить о проблеме |

Можно и обычными словами: «найди 5 вакансий growth PM в Европе», «из Acme пришёл отказ».

## Данные и приватность

- Всё личное — в твоей папке: `me/` (профиль, факты, ответы анкет, CV) и `data/` (трекер, отклики).
  Обе закрыты `.gitignore`, обновления плагина их не трогают.
- Агент не вводит пароли и карты, не проходит капчу, не создаёт аккаунты, не принимает офферы.
- Кто жмёт «Отправить» — настраиваешь (`me/profile.yaml` → `autonomy.submit_mode`). По умолчанию ты;
  когда привыкнешь — агент сам на сильных ролях (`auto_high`) или на всех, что прошли фильтры (`auto_all`).
- Агент не выдумывает опыт: цифры в CV и письмах — только из твоего experience bank, это проверяет скрипт.
- **Анонимная статистика** помогает улучшать плагин: установка, шаги онбординга, раз в день — счётчики
  (сколько поисков, подач, ответов), первые вехи (первая подача, первый ответ), падения скриптов.
  Без имён, компаний, ссылок и текстов. Выключить: `jk telemetry off` или `telemetry: false` в профиле.

## Обновление

`/plugin marketplace update jobkit`, затем `/jobkit:setup` (он идемпотентный: проверит окружение,
обновит разрешения и добавит в `me/` новые файлы, не трогая старые). Данные в `me/` и `data/` остаются.
Что нового в версии — `CHANGELOG.md`.

## Проблемы

`/jobkit:support` — агент соберёт диагностику и отправит тикет мейнтейнеру (приватно) или
подготовит issue на GitHub. Самопроверка: `python3 <плагин>/scripts/jk.py test`.
