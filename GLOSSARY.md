# Словарь

**Кандидат** — человек, для которого работает агент.

**Роль** — одна вакансия у одной компании, пара «компания — должность». Единица дедупа, тейлоринга и подачи.

**Трекер** — `data/tracker.csv`, единственный источник правды о каждой роли.

**ATS** — система найма компании (Greenhouse, Ashby, Lever…), чья форма принимает заявку.

**Борд** — страница вакансий одной компании на её ATS.

**Агрегатор** — сайт, собирающий чужие вакансии; гео и дате на нём не верим.

**Заход** — один проход `/jobs-run`: поиск, дедуп, гейты, тейлоринг, формы, отчёт.

**Батч** — роли, доведённые до кнопки отправки и отданные одним отчётом. Подтверждение действует только на них.

**Дедуп** — проверка по трекеру, что на эту роль ещё не подавались (`tracker.py check`).

**Гейт** — проверка до тейлоринга, которая снимает роль, не тратя на неё CV.

**Рубрика** — правило оценки: `match` с обязательным доказательством + `freshness`.

**Доказательство (evidence)** — конкретный факт из experience-bank, подтверждающий совпадение с вакансией.

**Трек** — вариант позиционирования: тайтл, саммари, истории под тип вакансий.

**Тейлоринг** — сборка CV и письма под конкретную роль.

**Overlay** — файл `cv.yaml` с тем, что меняется в CV под вакансию; тело берётся из `me/cv/base.yaml`.

**Experience bank** — `me/experience-bank.md`, единственный источник фактов о кандидате.

**Канон ответов** — `me/application-answers.md`, утверждённые ответы на типовые поля анкет.

**Письмо-кейс** — сопроводительное письмо, построенное как кейс под продукт работодателя.

**Граница подачи** — необратимый клик Submit; всё до него делает агент, кто жмёт — решает `submit_mode`.

**Стоп** — одно из пяти препятствий, которые агент не обходит: капча, оплата, пароль, создание аккаунта, 2FA/протухший логин.

**Лестница обходов** — порядок способов пройти упрямую форму перед тем, как сдаться.

**Эскалация** — возврат роли кандидату с готовым состоянием: форма заполнена максимально, спорное поле уже с рекомендованным ответом.

**Дефект флоу** — любая просьба к кандидату, кроме подтверждения отправки.

**Статусы**: `found` найдена · `ready` CV и письмо готовы · `applied` заявка ушла · `screening` разговор с рекрутёром · `interview` интервью · `test` тестовое · `final` финал · `offer` оффер · `rejected` отказ · `withdrawn` отозвал(а) сам(а) · `skipped` снята гейтом.
