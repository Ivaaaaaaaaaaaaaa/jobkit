Стандартный заход по вакансиям. Иди по шагам, после каждого — одна строка статуса.
Сколько подач: $ARGUMENTS (пусто — `search.per_run` из `me/profile.yaml`).

**Шаг 0. Готовность.** `python3 scripts/doctor.py` без ✗. В `me/` нет TODO по контактам, цели,
гео, деньгам — иначе сперва задай эти вопросы. Для форм — поднять Chrome-инструменты с
`file_upload` (`playbooks/forms.md` §0); не поднялись — заход идёт в режиме `draft_only`, скажи об этом.

**Шаг 1. Дела.** `python3 scripts/tracker.py due` — follow-up и дедлайны. Покажи кандидату коротко.
Статусы, о которых он мог забыть сказать («ответили ли из X?») — один вопрос.

**Шаг 2. Свежий поиск.** Как в /find: `scan.py`, разбор на ATS, гейты, оценка, запись в трекер.
Подаёмся в свежее: роль моложе недели бьёт висящую в `found`.

**Шаг 3. Очередь.** Топ по rank на нужное число подач + Medium-роли, если High не хватает.
Дедуп пачкой: `tracker.py check "К1::Р1" <url1> "К2::Р2" <url2> ...`.

**Шаг 4. Тейлоринг пачкой.** По каждой роли: CV overlay → аудит → рендер; бриф → письмо → аудит;
ответы. Статус `ready`.

**Шаг 5. Формы.** По одной роли — одна вкладка, заполнение целиком, CV, `form_check.js`.
Роли с капчей — в конец батча. Режим отправки — по `autonomy.submit_mode`.

**Шаг 6. Отчёт.** Прозой: найдено → снято (по гейтам) → готово к подтверждению (список: компания ·
роль · гео · вилка · балл · трек · CV · первая фраза письма · вкладка) → отправлено сам → что
нужно от кандидата (максимум один вопрос). Снятые ценнее поданных — по ним видно, где правило врёт.

**Шаг 7. После подтверждения.** Кандидат сказал «отправил» / «отправляй» — отправь (если просил),
проверь экран «спасибо», `tracker.py set <id> applied`, закрой вкладки по одной.
Назначь follow-up: `--next "follow-up" --date <+7 дней>`.

Новый вопрос анкеты — в `me/application-answers.md`. Новый способ обойти шаг — допиши в плейбук.
