Проведи онбординг кандидата по сценарию `playbooks/onboarding.md`. Правила агента — `CLAUDE.md`.

Вход: $ARGUMENTS (если указан файл или ссылка — начни блок 1 с них).

1. Шаг 0 сценария: создай `me/` и `data/`, скопируй шаблоны из `templates/` (существующие файлы
   не перезаписывай), прогони `python3 scripts/doctor.py`.
2. Если `me/profile.yaml` уже частично заполнен — скажи, что уже есть, и продолжи с первого
   блока, где остались TODO. Ничего не спрашивай повторно.
3. Веди блоки 1–5 по одному. После каждого блока — запиши в файлы и покажи короткую сводку.
4. Вопросы с вариантами задавай через AskUserQuestion.
5. В конце — `python3 scripts/doctor.py --test`, базовое CV через `scripts/render_cv.py --pdf`
   и предложение следующего шага (/cv-interview → /positioning → /find).

Тон дружелюбный, коротко, одна мысль в предложении. Чувствительное — объясни, зачем и где хранится.
