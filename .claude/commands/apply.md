Подготовь и подай заявку на одну роль: $ARGUMENTS

Канон — `CLAUDE.md` §2 (граница подачи), §5 (тексты), §6 (формы). Механика — `playbooks/forms.md`.

1. **Роль.** По ссылке или id найди запись в трекере; нет — прочитай вакансию и заведи (`found`).
   Дедуп: `python3 scripts/tracker.py check "Компания::Роль" <url>`. `⛔` — стоп, скажи почему.
2. **Гейты** (`playbooks/scoring.md` §1) на настоящем ATS. Открой форму до тейлоринга. Снята — запиши
   `skipped` с причиной и остановись.
3. **Оценка** — match, evidence, track. Low — скажи и спроси, подавать ли всё равно.
4. **CV.** `data/applications/<id>/cv.yaml` по треку из `me/positioning.md` и `playbooks/cv-guide.md`
   → `text_audit.py --kind summary` → `render_cv.py <overlay>` (+`--pdf`, если форма просит).
5. **Письмо и ответы** (если в форме есть поля): бриф → письмо по `playbooks/cover-letter.md` →
   `text_audit.py --kind letter --company <X>`; свободные ответы — в `answers.md`, каждый через аудит.
6. **Форма** по `autonomy.submit_mode`:
   - `draft_only` — отдай пути к CV, письму, ответам. Конец.
   - иначе: поднять Chrome-инструменты, новая вкладка, заполнить целиком, приложить CV,
     `form_check.js`. Поля без ответа в `me/application-answers.md` — лучший правдивый ответ +
     строка в отчёт.
7. **Отправка.** `confirm_each` — стоп перед Submit, отчёт по роли (формат `CLAUDE.md` §6) и
   «жду подтверждения». `auto_high` и балл ≥ порога, тест чистый, сомнений нет — отправь сам.
   После отправки — экран «спасибо», `tracker.py set <id> applied`, вкладку закрыть.
8. Новый вопрос анкеты и ответ кандидата — сразу в `me/application-answers.md` §5.

Пять стопов (капча, оплата, пароль, создание аккаунта, 2FA/протухший логин) не обходятся.
