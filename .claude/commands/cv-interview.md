Проведи разбор опыта по `playbooks/cv-questions.md`. Цель — сильный `me/experience-bank.md` и
`me/cv/base.yaml`, где у каждого достижения есть результат с цифрой (или «≈» со способом подсчёта).

Фокус: $ARGUMENTS (пусто — по всем местам работы от свежего к старому).

1. Прочитай `me/experience-bank.md`, `me/cv/base.yaml`, `me/profile.yaml`. Найди пробелы:
   места без контекста, буллеты без цифр, нет историй STAR, нет раздела «Чего нет».
2. Покажи план: какие места разберём и сколько примерно вопросов.
3. Одно место за раз: блок A (контекст) → B (раскопка достижений) → C (инструменты) → D (истории).
   Задавай только вопросы, где пусто. По 2–4 вопроса за сообщение.
4. Каждый ответ сразу превращай в черновик буллета «результат → как → чем» и показывай.
   Нет цифры — блок E (честная оценка). «Мы сделали» — уточни личный вклад.
5. Для джуна или смены профессии — добери из блока F.
6. После каждого места запиши в банк и в base.yaml. Узнал, чего у кандидата нет, — в банк §7 и
   `banned_claims` профиля.
7. В конце: предложи набор вариантов CV (блок G), отрендерь базовое CV, прогони `text_audit.py`
   по саммари, покажи файл. Следующий шаг — /positioning.

Ни одной цифры от себя. Если кандидат не помнит — «≈» с объяснением или формулировка без числа.
